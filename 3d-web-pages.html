3D web development

The web has
a third dimension.

Every modern browser ships a GPU-accelerated graphics pipeline. With a little JavaScript you can render real-time 3D — product viewers, data visualisations, games, art — with no plugin and no install.

01 · The platform

Three browser APIs do the heavy lifting

WebGL 2OpenGL ES 3.0 in the browser. Supported everywhere; the workhorse of 3D on the web.
WebGPUThe modern successor: compute shaders, lower overhead, modelled on Vulkan, Metal and D3D12.
WebXRTakes a scene into VR headsets and AR on phones, with tracked controllers and hands.

All three hand your code a canvas and a GPU. Everything else — cameras, lights, materials, models — is built on top.

02 · The tools

You rarely talk to the GPU directly

Raw WebGL takes hundreds of lines to draw a lit cube. Libraries give you a scene graph instead:

  • Three.js — the most widely used; small core, huge ecosystem.
  • Babylon.js — a full engine with physics, an inspector and a node material editor.
  • React Three Fiber — Three.js written as React components.
  • PlayCanvas — an engine plus a collaborative browser-based editor.
  • A-Frame — declarative HTML tags for VR and AR scenes.
03 · Shaders

Small programs that run on every vertex and pixel

The rippling sphere is one shader: the vertex stage pushes each point along its normal by a sum of sine waves, and the fragment stage colours it by that displacement.

// vertex shader (GLSL)
float d = sin(position.y * 4.0 + uTime)
        * sin(position.x * 3.0 + uTime);
vec3 p = position + normal * d * uAmp;
gl_Position = projectionMatrix
            * modelViewMatrix * vec4(p, 1.0);
04 · Performance

60 frames a second is 16.6 ms each

  • Draw calls matter most. Merge geometry and use instancing — the cubes here are one instanced draw.
  • Compress assets. glTF with Draco or Meshopt geometry and KTX2 textures.
  • Cap the pixel ratio. Rendering at 3× on a phone triples fill cost for little gain.
  • Pause when hidden. Stop the loop when the tab or canvas is off-screen.
  • Respect reduced motion. This page slows its animation when the OS asks it to.
05 · Get started

A spinning cube in twelve lines

import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight);
camera.position.z = 3;
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(),
  new THREE.MeshNormalMaterial());
scene.add(cube);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(innerWidth, innerHeight);
document.body.append(renderer.domElement);
renderer.setAnimationLoop(t => { cube.rotation.y = t / 1000; renderer.render(scene, camera); });
